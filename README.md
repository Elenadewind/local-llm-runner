local‑llm‑runner
Простой инструмент для запуска лёгких языковых моделей (LLM) на вашем устройстве без облачных сервисов. Идеален для приватности, офлайн/онлайн‑работы, обучения, тестирования и общения..

Не допускайте рисков, утечек данных в целях обеспечения безопасности и приватности и чините баги. Предлагайте улучшения. Идея для пользы людям.
